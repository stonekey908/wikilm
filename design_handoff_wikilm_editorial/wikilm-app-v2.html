Tool use in large

The central shift of 2023 was teaching language models to reach outside themselves: to call an API, query a database, execute a line of code. The arrival of tools closed the gap between reasoning and acting.

§ 01Origins

The earliest credible "tools-for-LLMs" paper was Toolformer, which showed that models can learn, in a self-supervised way, when to call a handful of simple tools. The follow-up wave — ReAct, Voyager, and the constellation of agentic systems in 2023–24 — built the scaffold we now take for granted.[1]

Tool use is not a capability. It is a training distribution.

§ 02Toolformer: self-taught

Meta's 2023 paper framed tool use as a self-supervised problem: the model is shown a corpus, invents candidate tool calls for each token, keeps the calls that reduce perplexity on the next tokens, and trains on the result. The tools tested were modest — a calculator, a calendar, a Wikipedia search — but the finding was profound. See also function calling for the productized descendant.

§ 03ReAct: think, act, observe

Where Toolformer bakes tool calls into the weights, ReAct structures them as a loop at inference: Thought → Action → Observation, repeated until the model stops. Almost every production agent framework you've used today is a thin wrapper on this loop.[2]

§ 04Scaling

By the end of 2024, frontier models shipped with native tool use, parallel tool calls, and structured output. The design question moved up a layer — from "can it call tools" to "can it design, sequence, and recover from a sequence of tool calls." This is the territory of agent memory.[3]

Executive brief · Tool use in LLMs

The shift of 2023 was teaching models to act, not just reason. Two lineages matter. Toolformer[1] bakes tool calls into weights via self-supervision. ReAct[2] structures Thought→Action→Observation loops at inference.

By 2024, frontier models ship with native tool use, parallel calls, and structured output. The next question is sequencing — agents that plan, execute, and recover. This is the territory of agent memory.[3]
