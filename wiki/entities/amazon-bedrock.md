# Amazon Bedrock

## Overview

Amazon Web Services (AWS) cloud offering for foundation models and agentic AI. Provides infrastructure and tools for deploying [[agentic-ai]] systems without building from scratch.

## Role in Banking Adoption ([[deloitte-agentic-ai-banking]])

Amazon Bedrock is identified as one of the practical near-term pathways for banks to deploy agentic AI. Rather than building proprietary agents, banks can leverage AWS's pre-built agentic capabilities.

## Strategic Implication

Vendor partnerships (Bedrock, Salesforce Agentforce, Google) represent a compromise between "build in-house" (high cost/risk) and "never adopt" (missed opportunity). Banks with limited AI expertise can access [[agentic-ai]] via cloud providers.

## Significance for Governance

Using vendor solutions complicates [[governance-frameworks]] and accountability: if Bedrock's agent misbehaves, is AWS responsible? The bank? Both? Regulatory clarity on this question is still emerging.
