# Genie 3

Large-scale [[world-models|world model]] developed by [[google-deepmind]] that generates diverse, interactive environments from text prompts and single images. Capable of real-time interaction (24fps, 720p) with emergent [[environmental-consistency]].

## Key Capabilities

- Real-time interactive environment generation (24fps, 720p resolution)
- Visual memory up to 1 minute in duration
- Frame-by-frame generation based on actions and world descriptions
- Simulation of physical phenomena, ecosystems, and fantastical worlds
- Support for [[sima-agents]] and multi-step agent training

## Architecture

- Generative model without explicit 3D representations
- Implicit spatial coherence and physics understanding
- Promptable world events and dynamic interactions

## Limitations

- Restricted agent action vocabularies
- Poor multi-agent coordination
- Limited geographic accuracy
- Weak text rendering
- Interaction duration capped at minutes

## Applications

- **Agent Training**: Provides diverse, procedurally-rich environments for [[agentic-ai]] research
- **Interactive Experience Generation**: Rapid prototyping of game-like environments without manual asset creation
- **World Simulation**: Supports [[world-models]] research at scale
