# Andrej Karpathy

Co-founder of [[openai]], former AI lead at [[tesla]], and the person who coined the term "[[vibe-coding]]."

## Relevance to This Wiki

Karpathy is the originator of the [[llm-wiki-pattern]] — the system this wiki is built on. On April 3, 2026, he posted on X that he had shifted from using AI to generate code to using it to organize knowledge. He described a working system where raw research materials go into a folder, an LLM builds and maintains a structured interlinked wiki from them, and the whole thing compounds over time without human editing.

His research wiki on a single topic grew to ~100 articles and 400,000 words.

The next day, he published an "[[idea-files|idea file]]" — a GitHub gist with the full architecture — designed to be pasted directly into an LLM agent. His reasoning: in the era of LLM agents, share the idea, not the code. The other person's agent customizes and builds it.

## Key Contributions Referenced

- Created the [[llm-wiki-pattern]] (raw/ → schema → wiki/)
- Coined "[[vibe-coding]]"
- Advocated for "[[idea-files]]" over traditional code sharing
- Described [[knowledge-compilation]] as the key metaphor — raw research gets "compiled" like source code
