# Obsidian

A free, cross-platform note-taking application that works with plain markdown files stored on your local computer. Functions as the "IDE" for viewing and browsing an [[llm-wiki-pattern]] wiki.

## Role in the LLM Wiki Pattern

As described in [[karpathy-second-brain-medium-article]], Obsidian serves as:

- **The viewer**: browse the wiki's interlinked markdown pages with rendered `[[wikilinks]]`
- **The graph**: visualize connections between pages
- **The clipper**: the Obsidian Web Clipper browser extension converts web pages to markdown files with one click, feeding the `raw/` folder

## Key Properties

- No vendor lock-in — everything is plain markdown files
- No subscription or cloud dependency
- If Obsidian disappears, you still have a folder of text files
- Works on Mac, Windows, Linux, and mobile
