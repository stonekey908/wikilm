# LLM Landscape 2026

**One-line summary**: Open-weight models have reached proprietary parity, Mixture-of-Experts is now the universal large-model architecture, and extended reasoning has become a baseline expectation in every flagship release.

## Core terms

- **Mixture-of-Experts (MoE)** — architecture with many specialist sub-networks; only a learned-gated subset fires per token. See [[concepts/mixture-of-experts]].
- **Active parameters** — the slice of a MoE model's total params actually used per forward pass; the real cost and speed driver.
- **Reasoning model** — LLM that generates a hidden scratchpad before answering; trades latency and token cost for accuracy on multi-step tasks. See [[concepts/reasoning-models]].
- **Open-weight** — model with publicly released weights (does not imply training data or full reproducibility).
- **Dense transformer** — classic architecture where all parameters activate per token; baseline for comparison with MoE.
- **Context window** — max token capacity per call; ranges 128K–2M across 2026 flagships.
- **Multimodal** — model accepting text + images (and sometimes audio/video) as input. See [[concepts/multimodal-llms]].
- **Parameter efficiency** — capability per unit of active compute; [[entities/deepseek]] and [[entities/mistral-ai]] lead on this metric.

## What NOT to confuse

- **Total parameters ≠ inference cost** — DeepSeek V3.2 at 671B MoE runs cheaper per token than many 70B dense models. Always ask "active params," not "total params."
- **Open-weight ≠ open-source** — released weights let you run the model; they don't give you training data, methodology, or full reproducibility. DeepSeek and Qwen are open-weight, not fully open-source.
- **Reasoning mode ≠ always better** — extended chain-of-thought adds latency and cost. For simple queries it's waste; reserve it for coding, math, and multi-step logic.
